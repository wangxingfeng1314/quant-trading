## 系统优化全面分析
- 深入审查 fetcher.py / backtester.py / storage.py / scanner.py / portfolio.py / config.py / push.py / scheduler / main.py 全部核心代码
- 从性能、架构、安全、可维护性、用户体验 5 个维度提出 18 项优化建议
- 关键发现：
  1. **性能瓶颈 #1**：backtester.py L112 `df.loc[:idx].copy()` 每日每股票全量拷贝 DataFrame，O(n²) 内存开销
  2. **性能瓶颈 #2**：scanner.py L131 信号逐条 INSERT，storage.py L635 交易明细逐条 INSERT，未用 executemany

  5. **可维护性**：无 DB 迁移系统（用 except pass 处理 ALTER TABLE），魔法数字硬编码
  6. **UX**：长任务无进度反馈，回测结果无法对比，无导出功能

## 实施全部 18 项优化（v0.3.1）
- **性能优化**：
  1. 回测引擎零拷贝：`df.loc[:idx].copy()` → `df.iloc[:idx+1]`（传视图，消除 O(n²) 内存拷贝）
  2. 批量写入：`save_signals_batch()` + `save_backtest_trades()` 改用 `executemany`
  3. 扫描器并行化：ThreadPoolExecutor + 可配置 worker 数（>=50 只股票自动启用）
  4. SQLite 连接池：`threading.local()` 线程级连接复用，避免频繁创建/关闭
- **架构优化**：
  5. fetcher.py 拆分：提取 `data/fetcher_base.py`（DataSource ABC + DAILY_COLUMNS）和 `data/fetcher_circuit.py`（CircuitBreaker + TokenBucket）
  6. 新增 Service 层：`services/` 包含 DataService/BacktestService/SignalService + validators.py 输入校验
  7. 魔法数字配置化：scanner/backtester/fetcher 的硬编码常量集中到 `core/config.py`
- **安全优化**：
  8. Streamlit 认证：`APP_AUTH_ENABLED` 环境变量控制，登录页 + session_state
  9. Webhook 日志脱敏：`_mask_url()` + `_safe_log()` 替代直接打印 URL
  10. 危险操作二次确认：数据库恢复需勾选确认框
- **可维护性**：
  11. DB 迁移系统：`PRAGMA user_version` + `_run_migrations()` 版本化迁移
  12. 自定义异常层次：`core/exceptions.py`（QuantError → DataFetchError/BacktestError/ValidationError/StorageError）
  13. requirements.txt 版本锁定说明
- **用户体验**：
  14. 信号扫描结果 CSV 导出 + 历史信号导出
  15. 回测结果对比模式：勾选多条历史记录，叠加权益曲线 + 指标对比表
  16. 自选股列表 CSV 导出
  17. 移动端响应式 CSS（@media 768px）
- **新增文件**：`core/exceptions.py`, `data/fetcher_base.py`, `data/fetcher_circuit.py`, `services/__init__.py`, `services/data_service.py`, `services/backtest_service.py`, `services/signal_service.py`, `services/validators.py`
- **测试**：89 个单元测试全部通过 ✅
