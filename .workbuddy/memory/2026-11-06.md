# 第二批：性能优化 + 样本外验证（v0.4.4）

## 性能：实测 3.5s → 0.37s（5 标的 × 2 年）

按剖析结果逐个消除，顺序很重要：

1. **`date_index` 用 `iterrows` 建** → 单次回测固定耗 2.7s（占 30%）。改 `{d: i for i, d in enumerate(df["trade_date"].tolist())}`
2. **真正的热点是 `df[col]`**：pandas 3.0 移除 `_item_cache`，宽表（30 列）每次取列重建 Series ≈ 45µs。
   → 新增 `engine/bar_view.py`：`BarFrame` / `BarSeries` 提供 DataFrame 接口子集（`__getitem__` / `iloc` / `columns` / `index` / `tolist()` / `pct_change()` / `rolling()` 等），底层直读 numpy；**未覆盖属性 `__getattr__` 自动回退真实 DataFrame**。
   - 关键设计：回退机制保证策略零改动、正确性优先
   - 四条内置策略实测提速 2.5~8 倍，指标与 DataFrame 路径**完全一致**（对拍验证）
3. **主循环 `df.iloc[idx]["close"]`** → `_StockArrays.val("close", idx)` 直读 numpy
4. **ST 标记 / 基准收益模块级缓存**：`get_instrument_list()` + iterrows 建 st_lookup、基准指数日线，原先每次 `run()` 重做，网格搜索 N 组合 = N 次。现 TTL + LRU，`clear_backtester_cache()` 失效
5. **`preload_backtest_data` 加 LRU**：网格/多折复用同一份预计算指标
6. `grid_search()` 新增 `preloaded_data` 入参（样本外验证跨折复用）

测试套件耗时 66.9s → 23.7s

## 样本外验证框架（`engine/validation.py`，657 行）

- `walk_forward()`：切 n 折，每折训练段网格挑参 → 紧随其后的测试段运行（严格不参与选参）→ 各折测试段权益按比例首尾拼接
- `parameter_stability()`：最优组合 vs 「只差一档」邻居，`邻居均值/最优值` ≥0.7 稳健、<0.5 孤立尖峰
- `monte_carlo_trades()`：**双口径**
  - 重排（permutation）：求和不变，只测路径风险（回撤可能多深）
  - 自助重采样（bootstrap）：才有收益分布，亏损概率取自这里
  - 这个拆分很关键 —— 一开始只做重排，"亏损概率"只能是 0% 或 100%，没有分布意义，是自己踩到后修正的
  - `observed_realized_drawdown`（已实现盈亏口径）vs `observed_drawdown`（组合盯市口径）显式区分，避免用错基准比较
- 新增 `drawdown_samples` / `return_samples`（≤400 点降采样）供 UI 画直方图

## 实测结论（ma_cross, 5 标的, 2020-2024, 4 折）

```
样本内均值 -3.38 → 样本外均值 1.50（样本内非正，效率不适用）
拼接样本外：收益 5.87% 回撤 6.26% 夏普 0.36
参数稳定性 -5.92（脆弱，孤立尖峰）
自助重采样：收益 90% 区间 -5.21% ~ 8.15%，亏损概率 39%
结论：过拟合风险高 —— 策略连样本内都不赚钱，最优参数缺乏选择依据
```
